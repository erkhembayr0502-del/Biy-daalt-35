1. Дадлага ба оюутны төсөл: Анхны туршлагыг хэрхэн олох вэ?

Програм хангамжийн инженерчлэлийн чиглэлээр суралцаж буй оюутнуудын хувьд анхны туршлага олж авах нь 
карьерын хөгжлийн чухал алхам юм. Туршлагагүй байсан ч өөрийн ур чадварыг хөгжүүлж, бодит төсөл дээр
ажиллах олон боломж байдаг.

Юуны өмнө сургууль болон компаниудын санал болгодог дадлагын хөтөлбөрүүдэд хамрагдах хэрэгтэй. Мөн
өөрийн сонирхсон чиглэлээр жижиг хэмжээний хувийн төсөл хэрэгжүүлж GitHub дээр нийтлэх нь туршлага
хуримтлуулах сайн арга болдог. Үүнээс гадна багийн төсөл, судалгааны ажил, hackathon зэрэг арга
хэмжээнд оролцсоноор бодит орчинд ажиллах туршлага олж авна.

Анхны туршлага нь заавал цалинтай ажил байх албагүй. Хувийн болон багийн төслүүд, сайн дурын үйл
ажиллагаа ч гэсэн ирээдүйд ажилд ороход үнэтэй туршлага болдог.


2. Туршлагагүй оюутан анхны туршлагаа хаанаас авах вэ?

Туршлагагүй оюутнууд дараах боломжуудаас анхны туршлагаа хуримтлуулж болно:

Компаниудын дадлагын хөтөлбөрүүд
Hackathon болон програмчлалын олимпиад
Нээлттэй эхийн (Open Source) төслүүд
Сургуулийн доторх багийн болон судалгааны төслүүд
Сайн дурын ажил, клубийн үйл ажиллагаа
HackerRank, LeetCode зэрэг онлайн платформууд
Хувийн төсөл (Pet Project)

Эдгээр үйл ажиллагаанд оролцсоноор техникийн мэдлэгээс гадна багаар ажиллах, харилцах, асуудал
шийдвэрлэх чадвараа хөгжүүлж чадна.

3. Дадлагын хөтөлбөрүүд, Hackathon, олимпиад, нээлттэй эх, сургуулийн төслүүд, сайн дурын ажил
-Дадлагын хөтөлбөрүүд

Оюутнууд байгууллагын ажлын орчинтой танилцаж, бодит төсөл дээр ажиллах боломжтой. Дадлага нь
ирээдүйн ажлын байрны суурь болж өгдөг.

-Hackathon ба олимпиад

Богино хугацаанд тодорхой асуудлыг шийдвэрлэх замаар программчлал, багаар ажиллах, бүтээлч
сэтгэлгээний чадвараа хөгжүүлдэг.

-Нээлттэй эхийн төслүүд (Open Source)

GitHub дээр байрлах төслүүдэд хувь нэмэр оруулснаар бодит хөгжүүлэлтийн орчинд ажиллах туршлага
хуримтлуулж, олон улсын хөгжүүлэгчидтэй хамтран ажиллах боломж бүрдэнэ.

-Сургуулийн доторх төслүүд

Хичээлийн төсөл, судалгааны ажил, багийн даалгавар зэрэг нь програм хөгжүүлэлтийн бодит үйл явцыг
суралцах хамгийн ойр боломж болдог.

-Сайн дурын ажил

Оюутны клуб, арга хэмжээ зохион байгуулах зэрэг үйл ажиллагаанд оролцсоноор манлайлал, зохион
байгуулалт, харилцааны ур чадвар сайжирдаг.
